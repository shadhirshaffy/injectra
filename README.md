# injectra
Injectra is an AI security gateway for detecting and preventing prompt injection attacks using hybrid detection, configurable guardrails, LLM protection, RAG security, and real-time threat monitoring.


## Project status

Phase 1 defines the MVP architecture and implementation contracts. The backend currently exposes health only; the frontend is a scaffold. Product endpoints described in the designs are planned work.
